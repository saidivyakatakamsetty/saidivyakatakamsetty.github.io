## Tech

Built with pure HTML, CSS, and vanilla JavaScript. No frameworks, no build step, and a single `index.html` file.

- **Font:** Inter
- **Design:** Clean, professional layout with light and dark mode
- **Interactions:** Custom cursor · Cursor spotlight on cards · Magnetic buttons · Subtle 3D tilt · Typing headline · Count-up stats · Scrolling tools strip · Scroll progress bar · Scroll reveal animations
- **Visuals:** Tool logos and project cover art built into the page
- **Accessibility:** Respects reduced-motion settings; cursor effects run on desktop only
- **Responsive:** Mobile and desktop
- Deploys instantly via GitHub Pages
